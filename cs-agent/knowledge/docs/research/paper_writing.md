# 论文写作指南

## 论文结构

### 1. Title（标题）
- 简洁、准确、有吸引力
- 包含关键词
- 避免缩写（除非是领域公认的）

### 2. Abstract（摘要）
- 200-300 字
- 包含：问题、方法、结果、结论
- 最后写（全文完成后提炼）

### 3. Introduction（引言）
- 研究背景和动机
- 相关工作简述
- 研究问题和贡献
- 论文组织结构

### 4. Related Work（相关工作）
- 按主题分类，不是简单罗列
- 指出现有工作的不足
- 说明你的工作如何改进

### 5. Method（方法）
- 详细描述你的方法
- 使用公式、图表辅助说明
- 伪代码（如果是算法）

### 6. Experiments（实验）
- **数据集**: 说明来源、规模、划分
- **基线方法**: 选择合理的对比方法
- **评估指标**: Accuracy, Precision, Recall, F1, BLEU, ROUGE 等
- **消融实验**: 验证各组件的贡献
- **结果分析**: 不仅报告数字，还要分析原因

### 7. Conclusion（结论）
- 总结贡献
- 局限性
- 未来工作方向

## 常用顶会

### 人工智能 / 机器学习
- **NeurIPS**: 神经信息处理系统
- **ICML**: 国际机器学习会议
- **ICLR**: 国际学习表征会议
- **AAAI**: 美国人工智能协会
- **IJCAI**: 国际人工智能联合会议

### 自然语言处理
- **ACL**: 计算语言学协会
- **EMNLP**: 语言处理的经验方法
- **NAACL**: 北美计算语言学

### 计算机视觉
- **CVPR**: 计算机视觉与模式识别
- **ICCV**: 国际计算机视觉会议
- **ECCV**: 欧洲计算机视觉会议

### 数据库 / 数据挖掘
- **SIGMOD**: 数据管理
- **VLDB**: 超大型数据库
- **KDD**: 知识发现与数据挖掘

### 系统 / 网络
- **OSDI**: 操作系统设计
- **SOSP**: 操作系统原理
- **SIGCOMM**: 数据通信
- **NSDI**: 网络系统设计

## 论文阅读方法

### 三遍阅读法
1. **第一遍（5-10 分钟）**: 标题、摘要、引言、结论、图表
2. **第二遍（1 小时）**: 通读全文，理解关键内容，标记不理解的部分
3. **第三遍（4-5 小时）**: 尝试重新推导，深入理解每个细节

### 阅读笔记模板
```
论文标题:
作者:
会议/年份:
研究问题:
主要方法:
关键创新:
实验结果:
个人评价:
可改进方向:
```
