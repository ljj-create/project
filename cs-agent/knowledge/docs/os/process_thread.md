# 进程与线程

## 进程（Process）
- **定义**: 程序的一次执行实例，是资源分配的基本单位
- **组成**: 代码段、数据段、堆、栈、PCB（进程控制块）
- **PCB 包含**: PID、程序计数器、寄存器、内存管理信息、I/O 状态

## 线程（Thread）
- **定义**: 进程中的执行单元，是 CPU 调度的基本单位
- **组成**: 线程 ID、程序计数器、寄存器、栈
- **共享**: 代码段、数据段、堆、文件描述符

## 进程 vs 线程
| 特性 | 进程 | 线程 |
|------|------|------|
| 资源分配 | 独立地址空间 | 共享进程地址空间 |
| 创建开销 | 大（复制地址空间） | 小 |
| 切换开销 | 大（切换页表等） | 小 |
| 通信方式 | IPC（管道、消息队列、共享内存等） | 直接读写共享变量 |
| 健壮性 | 一个进程崩溃不影响其他 | 一个线程崩溃整个进程退出 |

## 进程间通信（IPC）
1. **管道（Pipe）**: 半双工，父子进程间通信
2. **命名管道（FIFO）**: 无亲缘关系进程间通信
3. **消息队列**: 内核中的消息链表
4. **共享内存**: 最快的 IPC 方式，需要同步机制
5. **信号量**: 用于同步，控制对共享资源的访问
6. **Socket**: 可用于不同机器间的进程通信

## 进程调度算法
1. **FCFS（先来先服务）**: 非抢占，简单但可能导致长作业阻塞短作业
2. **SJF（短作业优先）**: 平均等待时间最短，但可能导致长作业饥饿
3. **RR（时间片轮转）**: 每个进程分配固定时间片，适合交互式系统
4. **优先级调度**: 可能导致低优先级饥饿（老化机制解决）
5. **MLFQ（多级反馈队列）**: 结合多种策略，Linux CFS 的基础

## 协程（Coroutine）
- **定义**: 用户态轻量级线程，由程序自身控制切换
- **优势**: 无内核态切换开销，内存占用小
- **应用**: Python asyncio、Go goroutine、Lua coroutine

## 死锁
### 必要条件
1. **互斥**: 资源不能被共享
2. **占有并等待**: 持有资源的同时等待其他资源
3. **不可剥夺**: 资源不能被强制收回
4. **循环等待**: 存在等待环

### 处理策略
- **预防**: 破坏必要条件
- **避免**: 银行家算法
- **检测+恢复**: 检测死锁后回滚
- **忽略**: 鸵鸟策略（大多数 OS 采用）
