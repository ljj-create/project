# 排序算法

## 比较排序

### 冒泡排序（Bubble Sort）
- **时间复杂度**: 平均/最坏 O(n²)，最好 O(n)
- **空间复杂度**: O(1)
- **稳定性**: 稳定
- **思想**: 相邻元素比较交换，每轮将最大元素"冒泡"到末尾

### 选择排序（Selection Sort）
- **时间复杂度**: O(n²)
- **空间复杂度**: O(1)
- **稳定性**: 不稳定
- **思想**: 每轮选择最小元素放到已排序序列末尾

### 插入排序（Insertion Sort）
- **时间复杂度**: 平均/最坏 O(n²)，最好 O(n)
- **空间复杂度**: O(1)
- **稳定性**: 稳定
- **思想**: 将元素插入到已排序序列的正确位置
- **适用**: 小规模数据或基本有序的数据

### 归并排序（Merge Sort）
- **时间复杂度**: O(n log n)
- **空间复杂度**: O(n)
- **稳定性**: 稳定
- **思想**: 分治法，将数组分成两半，分别排序后合并
- **应用**: 外部排序、链表排序

### 快速排序（Quick Sort）
- **时间复杂度**: 平均 O(n log n)，最坏 O(n²)
- **空间复杂度**: O(log n)
- **稳定性**: 不稳定
- **思想**: 选择 pivot，将数组分为小于和大于 pivot 的两部分，递归排序
- **优化**: 三数取中、随机化 pivot、小规模切换插入排序

### 堆排序（Heap Sort）
- **时间复杂度**: O(n log n)
- **空间复杂度**: O(1)
- **稳定性**: 不稳定
- **思想**: 建最大堆，依次将堆顶（最大值）移到末尾

## 非比较排序

### 计数排序（Counting Sort）
- **时间复杂度**: O(n + k)，k 为值域范围
- **空间复杂度**: O(k)
- **稳定性**: 稳定
- **适用**: 值域范围较小的整数排序

### 基数排序（Radix Sort）
- **时间复杂度**: O(d × (n + k))，d 为位数
- **空间复杂度**: O(n + k)
- **稳定性**: 稳定

### 桶排序（Bucket Sort）
- **时间复杂度**: 平均 O(n + k)
- **空间复杂度**: O(n + k)
- **适用**: 数据均匀分布

## 排序算法选择指南
| 场景 | 推荐算法 |
|------|---------|
| 通用场景 | 快速排序 |
| 需要稳定性 | 归并排序 |
| 内存受限 | 堆排序 |
| 数据基本有序 | 插入排序 |
| 小规模数据 | 插入排序 |
| 整数且值域小 | 计数排序 |
