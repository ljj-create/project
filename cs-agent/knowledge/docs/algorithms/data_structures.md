# 常用数据结构

## 数组（Array）
- **特点**: 连续内存存储，O(1) 随机访问
- **操作复杂度**: 访问 O(1)，插入/删除 O(n)
- **应用场景**: 需要频繁随机访问的场景

## 链表（Linked List）
- **特点**: 非连续内存，通过指针连接
- **操作复杂度**: 访问 O(n)，插入/删除 O(1)（已知位置）
- **变体**: 单链表、双链表、循环链表
- **应用场景**: 频繁插入/删除的场景，如 LRU 缓存

## 栈（Stack）
- **特点**: LIFO（后进先出）
- **操作**: push O(1)，pop O(1)，peek O(1)
- **应用场景**: 函数调用栈、括号匹配、表达式求值、DFS

## 队列（Queue）
- **特点**: FIFO（先进先出）
- **操作**: enqueue O(1)，dequeue O(1)
- **变体**: 双端队列（Deque）、优先队列（Priority Queue）
- **应用场景**: BFS、任务调度、消息队列

## 哈希表（Hash Table）
- **特点**: 键值对存储，平均 O(1) 查找
- **冲突解决**: 链地址法、开放寻址法
- **应用场景**: 缓存、去重、计数器

## 树（Tree）

### 二叉搜索树（BST）
- 左子树所有节点 < 根 < 右子树所有节点
- 操作: 查找、插入、删除均为 O(log n)（平衡时）
- 最坏情况退化为链表 O(n)

### AVL 树
- 自平衡 BST，任意节点左右子树高度差 ≤ 1
- 通过旋转保持平衡

### 红黑树
- 自平衡 BST，通过颜色标记和旋转规则保持近似平衡
- 插入/删除/查找均为 O(log n)
- 应用：Linux 内核调度器、Java TreeMap

### B 树 / B+ 树
- 多路平衡搜索树
- B+ 树：所有数据在叶子节点，叶子节点有序链表
- 应用：数据库索引、文件系统

### 堆（Heap）
- 最大堆：父节点 ≥ 子节点
- 最小堆：父节点 ≤ 子节点
- 操作：插入 O(log n)，删除堆顶 O(log n)，建堆 O(n)
- 应用：优先队列、堆排序、Top-K 问题

## 图（Graph）
- **表示**: 邻接矩阵、邻接表
- **遍历**: BFS（广度优先）、DFS（深度优先）
- **最短路径**: Dijkstra（非负权）、Bellman-Ford（含负权）、Floyd（全源）
- **最小生成树**: Prim、Kruskal
- **拓扑排序**: DAG 的线性排序
